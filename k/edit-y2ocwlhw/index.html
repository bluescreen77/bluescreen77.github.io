먼저 준비물

프롬프트 5줄

1

도구 깔고 확인

영상 만들 도구가 다 있는지 클로드가 확인하고, 없으면 깔아 줘요.

이 폴더에서 세로 릴스(1080×1920)를 만들 거야. Node.js 22 이상, FFmpeg가 있는지 확인하고 없으면 설치해 줘. 그다음 npx hyperframes init 릴스 --example blank --resolution portrait --non-interactive 로 프로젝트를 만들고, npx hyperframes doctor 결과를 보여 줘. Node.js·FFmpeg·Chrome 말고 Docker·whisper·TTS·MusicGen 같은 선택 항목은 깔지 마.

doctor 결과는 Node.js·FFmpeg·Chrome 줄만 보세요. 빨간색일 때만 그 줄을 클로드에게 붙여 넣으면 돼요. 나머지 줄은 무시해도 돼요.

2

바로 만들지 말고 장면표부터

장면 순서·자막·길이를 표로 먼저 받아요. 고치는 건 말로.

주제는 「여기에 주제」. 바로 만들지 말고 장면표부터 보여 줘. 장면마다 자막 한 줄(띄어쓰기 포함 14자 안), 보여 줄 화면 하나, 길이(초). 전체 30초 안. 첫 장면은 3초 안에 궁금해지게.

AI 티의 절반은 순서 문제예요. 「3번 장면 자막 더 짧게」처럼 말로 고치세요. 「여기에 주제」 자리에 내 주제를 넣으세요.

3

스타일은 파일 하나로 고정

색 2개·글꼴 1개·자막 위치를 파일로 정해, 매번 같은 채널처럼 보여요.

스타일.md 파일을 만들어 줘. 바탕색 1개와 강조색 1개(글자는 흰색 또는 검정 하나), 글꼴 1개(Pretendard 굵게 — @font-face 로 https://cdn.jsdelivr.net/npm/pretendard@1.3.9/dist/web/static/woff2/Pretendard-ExtraBold.woff2 를 불러와), 자막은 위 250px 바로 아래에 한 줄(띄어쓰기 포함 14자 안), 낱말 중간에서 줄 바꾸지 않기. 위 250px·아래 440px·오른쪽 140px는 비워 두기(인스타 버튼 자리). 첫 프레임에 제목이 보이게. 앞으로 모든 영상은 이 파일을 따라 줘.

비워 두는 자리(위 250px·아래 440px·오른쪽 140px)는 릴스의 좋아요·댓글 버튼과 캡션이 덮는 곳이에요.

4

「멋있게」 말고 효과 이름으로

휩 팬·숫자 올라가기·자막 강조를 이름으로 시켜요.

2번 장면으로 넘어갈 때 휩 팬(whip-pan-cut)을 쓰고, 숫자는 0부터 올라가게(count-up), 자막은 낱말마다 강조색이 차례로 들어가게(caption-highlight) 해 줘. npx hyperframes catalog 로 찾아서 npx hyperframes add <이름> --no-clipboard 로 넣고, 가로(1920×1080)로 된 것은 세로·한글·스타일.md 에 맞게 고쳐 줘.

「멋있게 해 줘」는 매번 다르게 나와요. 이름은 아래 효과 이름 사전에서 고르세요.

5

소리 맞추고, 사진으로 먼저 확인

장면 사진을 먼저 보고, 괜찮으면 -14 LUFS로 영상 뽑기.

효과음은 장면이 바뀔 때만 넣고 배경음은 작게(소리 파일은 ffmpeg 로 직접 만들어도 돼, 유료 서비스는 쓰지 마. <audio> 마다 id 를 붙여). npx hyperframes check 로 오류를 먼저 없애고, npx hyperframes snapshot --at <장면마다 한 시각> -o 사진 으로 장면 사진을 보여 줘. 내가 괜찮다고 하면 렌더하고, ffmpeg loudnorm 을 두 번 돌려(two-pass) -14 LUFS 에 맞춰서 Exports 폴더에 저장한 뒤 ebur128 로 잰 값을 알려 줘.

인스타는 소리를 약 -14 LUFS로 맞춰요. 미리 맞추면 작게 묻히지 않아요. 장면 사진은 사진 폴더에 저장돼요.

효과 이름 사전

HyperFrames 공식 목록(v0.8.206)에 실제로 있는 이름만 골랐어요. 이름을 누르면 복사돼요.

가로(1920×1080)로 만들어진 것 — 쓰려면 「세로로 고쳐 줘」를 덧붙이세요: 줌 블러 전환 cinematic-zoom, 지지직 전환 glitch, 빛 번짐 light-leak, 공항 전광판 숫자 split-flap-board, 박자 멈춤 컷 beat-freeze-cut. 그리고 위 표의 자막 효과도 처음엔 영어·가로 기준이라 「한글·세로·스타일.md 에 맞게」 고치게 됩니다.

전체 목록은 npx hyperframes catalog — 448개가 나와요.

막히면

무료로 되나요?

도구(HyperFrames·FFmpeg·Node.js)는 무료예요. Claude Code를 쓰려면 Claude 유료 요금제가 필요합니다.

윈도우도 되나요? 맥 전용 아니에요?

둘 다 돼요. 이 키트는 윈도우 11에서 만들었습니다.

렌더한 영상에 소리가 없어요

<audio>에 id가 없으면 렌더에서 빠집니다. 렌더 전에 npx hyperframes check를 돌리세요.

글꼴이 기본 글꼴로 나와요

Pretendard는 링크만 걸면 안 되고 @font-face로 woff2 파일을 불러와야 해요. 3번 프롬프트에 주소가 들어 있습니다.

-14 LUFS가 안 맞아요 (-20, -15가 나와요)

목소리 없이 배경음만 작으면 너무 조용해서 한 번에 안 맞아요. loudnorm을 두 번 돌리거나 배경음을 조금 키운 뒤 다시 하세요. 저희는 두 번 돌려 -14.1이 나왔어요.

한글 자막이 어색하게 끊겨요

「자막은 한 줄 14자 안, 낱말 중간에서 줄 바꾸지 마」라고 스타일.md에 적어 두세요.

렌더가 너무 오래 걸려요

먼저 snapshot으로 사진만 확인하고, 다 고친 뒤 한 번만 렌더하세요. 30초 영상이 저희 컴퓨터에서 46초~2분 걸렸어요.

doctor에 빨간 줄이 많아요

Docker·TTS·whisper·MusicGen·Version 줄은 이 키트에 필요 없어요. Node.js·FFmpeg·Chrome만 초록이면 됩니다.

효과가 가로 화면으로 나와요

목록의 상당수가 1920×1080 가로예요. 「세로·스타일.md에 맞게 고쳐 줘」라고 하세요.

숫자가 중간에 사라져요

효과 안쪽 길이가 장면보다 짧아서예요. 「count-up 길이를 장면 길이에 맞춰 줘」라고 하세요.

장면 사진이 어디 있어요?

5번 프롬프트처럼 -o 사진을 붙이면 「사진」 폴더에 저장돼요. 안 붙이면 숨김 폴더(.hyperframes)에 들어갑니다.

남이 잘 만든 영상을 내려받아 따라 해도 되나요?

남의 영상을 내려받는 건 플랫폼 약관에 걸릴 수 있어요. 링크를 보면서 「색·자막 위치·장면 길이」처럼 특징만 적어 클로드에게 주세요. 베끼지 말고 영감만.

Remotion도 쓰라던데요?

Remotion은 회사 규모에 따라 유료 라이선스가 필요할 수 있어요. 이 키트는 HyperFrames만으로 무료로 됩니다.
